# nice-skills

实用 Agent 技能，现统一收录在 `notebook/nice-skills/`。

| 目录 | 用途与文件关系 |
| --- | --- |
| [bilibili-video-summary1/](bilibili-video-summary1/) | B 站视频搜索、字幕提取与内容总结，使用说明在 `SKILL.md`。 |
| [pc-maintenance/](pc-maintenance/) | Windows 电脑维护，`SKILL.md` 是技能入口，`README.md` 是补充说明，`scripts/` 存放 PowerShell 实现。 |

电脑维护脚本中，`performance_check.ps1` 用于性能检查，`system_health.ps1` 用于系统健康检查，`disk_cleanup.ps1` 用于磁盘清理。运行前阅读对应说明并检查参数。
